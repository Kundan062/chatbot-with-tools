# Chatbot

A polished AI chatbot demo that highlights backend tool integration and frontend conversational workflow design.

## Project Summary

This repository contains a focused chatbot project intended to demonstrate the core architecture of a conversational AI system.
It includes:

- `toolbackend.py` — backend application logic that processes user input, manages tool interactions, and returns structured chatbot responses.
- `toolfrontend.py` — frontend interface that captures user messages and presents chat output in a user-friendly format.

## Key Features

- Clean separation of backend and frontend responsibilities
- Simple tooling architecture suitable for extending with additional services or NLP components
- Recruiter-ready demonstration of practical chatbot implementation

## Skills Demonstrated

- Python application structure
- Backend/frontend integration
- Conversational AI workflow design
- Readable, maintainable code organization

## Getting Started

1. Open a terminal in the `Chatbot` folder.
2. Install any required Python packages if needed.
3. Run the backend script:

```bash
python toolbackend.py
```

4. Run the frontend script:

```bash
python toolfrontend.py
```

## How to Evaluate

- Review `toolbackend.py` for backend logic and chat handling patterns.
- Review `toolfrontend.py` for user interaction flow and messaging structure.
- Use this project as a starting point for adding API integrations, advanced NLP, or UI improvements.
